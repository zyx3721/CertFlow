# CertFlow v1.1.0 版本更新日志

**发布日期**: 2026-09-20  
**提交数量**: 15 次提交  
**版本类型**: 功能更新

---

## 📋 版本概述

新增企业微信扫码登录能力，支持「直连企业微信」与「统一认证中心（wecom-auth-center）」两种接入方式，覆盖认证配置、扫码登录、账号绑定/解绑与审计全链路。同步重整项目文档为双语主文档结构，部署文档对齐 Release 二进制发布产物，并增强 CI 镜像与本地启停脚本。

---

## ✨ 新增特性

- 新增企业微信扫码登录，支持「直连企业微信」与「统一认证中心」两种认证方式，认证配置面板卡片式切换。
- 新增企微账号绑定/解绑：右上角用户菜单按 `wecomBound` 状态显示「绑定企微/解绑企微」，绑定采用弹窗扫码并回告主窗口。
- 新增「基础配置 → 安全时效 → 企业微信扫码有效期」配置项（1-60 分钟，默认 5 分钟），企微授权 state 按配置动态签名。
- 登录方式下拉新增「企业微信」，选择后展示扫码说明卡片，回跳后以独立授权处理视图完成登录。
- 新增后端和前端服务启停脚本，便于本地开发快速启停。

---

## 🐛 Bug 修复

- 修复会话表 `auth_provider` CHECK 约束未包含 `wecom`，导致企业微信扫码登录写入会话失败的问题（新增 003 迁移）。
- 修复企业微信回调地址前缀尾部斜杠处理与预期不一致，误填多个尾斜杠时回调地址拼接出错的问题。

## 🔧 重构优化

- 用户菜单企微绑定入口重构为单按钮交互，绑定状态由用户对象 `wecomBound` 字段携带，减少独立查询请求。
- 登录页企微扫码卡片、授权处理视图、pageshow 往返缓存兜底与弹窗拦截提示对齐成熟交互规范。
- 密码可见切换按钮默认可点击，不再受字段禁用或空值限制；企微配置步骤卡片背景改用主题变量。
- 认证配置面板显示名称默认禁用编辑；LDAP 启用提示语明确为 AD/LDAP 认证登录方式。
- 角色权限目录中认证配置相关权限描述补充企业微信。

## 🔄 API 变更

- 新增 `GET /api/v1/auth/wecom/authorize`：获取企业微信扫码授权地址（直连/统一认证中心模式自适应）。
- 新增 `POST /api/v1/auth/wecom/callback`、`POST /api/v1/auth/wecom/sso/callback`：企微扫码登录回调，换取会话。
- 新增 `GET /api/v1/auth/wecom/bind-url`、`POST /api/v1/auth/wecom/bind`、`POST /api/v1/auth/wecom/sso/bind`、`DELETE /api/v1/auth/wecom/bind`：企微账号绑定与解绑。
- 新增 `GET`、`PUT /api/v1/settings/auth-provider/wecom`：企业微信认证配置管理，Secret 加密保存且不回显。
- 用户对象新增 `wecomBound` 字段，登录、`/api/v1/auth/me` 与用户列表均返回。

---

## 📊 数据库变更

- 新增迁移 `002_wecom_auth.sql`：创建企业微信账号绑定表 `user_wecom_bindings`（`wecom_userid` 唯一），并写入企业微信认证提供方默认配置行。
- 新增迁移 `003_wecom_session_provider.sql`：将会话表 `auth_provider` CHECK 约束扩展为允许 `wecom`。

## 🔄 升级说明

- 重启后端服务即自动执行 002、003 迁移，无需手工执行 SQL。
- 企业微信授权 state 使用 `JWT_SECRET` 签名，生产环境必须配置固定且足够随机的值；`PKI_KEY_ENCRYPTION_KEY` 加密企微 Secret，务必妥善备份。
- 直连模式需在企业微信管理后台配置应用可信域名与企业可信 IP；统一认证中心模式需在认证中心为本系统登记 `domain` 与 `callback_path: /login`，并保证双侧应用密钥一致。
- 文档结构调整：原 README 完整内容位于 `docs/README.md`，主 README 仅保留摘要与两种部署路径。
- 升级前建议按既有流程备份 PostgreSQL 数据库。
