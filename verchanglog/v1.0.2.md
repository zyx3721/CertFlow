# CertFlow v1.0.2 版本更新日志

**发布日期**: 2026-07-26  
**提交数量**: 1 次提交  
**版本类型**: 问题修复

---

## 📋 版本概述

修复经容器内 Nginx 反向代理部署时，操作审计来源 IP 被错误记录为 `127.0.0.1` 的问题。

---

## ✨ 新增特性

- 本版本无新增特性

---

## 🐛 Bug 修复

- 修复审计日志仅记录容器内 Nginx 回环地址的问题
- 支持从可信本机反代传递的 `X-Forwarded-For` 与 `X-Real-IP` 中识别合法客户端 IP
- 非本机反代请求继续使用实际连接地址，避免直接信任可伪造的请求头

---

## 🚀 性能优化

- 本版本无独立性能优化项

---

## 🔧 重构优化

- 拆分来源地址解析、回环地址识别与合法 IP 校验逻辑，提升审计来源解析的可维护性

---

## 📚 文档更新

- 补充 README 中 Nginx 反代场景的审计来源 IP 配置说明

---

## 🔄 API 变更

- 无 API 路径、请求参数或响应结构变更

---

## 📊 数据库变更

- 无数据库结构或迁移变更

---

## 🔄 升级说明

- 无需执行数据库迁移
- 更新部署镜像后，新生成的审计日志会记录客户端来源 IP；既有审计记录不会回填
- 自定义 Nginx 反代时，请保留 `X-Real-IP` 与 `X-Forwarded-For` 请求头配置
