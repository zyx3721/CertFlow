# 前端 Select 下拉定位规范

CertFlow 所有业务选择器统一复用 `frontend/src/components/ui/select.tsx`，禁止直接使用浏览器原生 `<select>`。

## 定位语义

- `SelectContent` 默认使用 Radix Select 的 `popper` 定位。
- 下拉层通过 Portal 挂载，不受卡片、表格滚动容器或弹窗内容区的 `overflow` 裁切。
- Radix 根据视口空间自动选择向上或向下展开，并限制为可用视口高度。
- 内容宽度默认跟随触发器宽度；业务页面不自行覆盖定位算法。

## 页面与场景

| 页面     | 选择器                                                | 所在场景                           | 定位要求                                                                            |
| -------- | ----------------------------------------------------- | ---------------------------------- | ----------------------------------------------------------------------------------- |
| CA 管理  | CA 类型、算法、上级 CA                                | 创建弹窗                           | Portal + popper，允许按视口自动翻转                                                 |
| 证书管理 | 状态、签发 CA、导出范围、导出格式、每页条数、撤销原因 | 表格工具栏、导出与撤销弹窗、分页栏 | 使用 Portal + popper，不被表格或弹窗裁切，并按视口空间自动调整展开方向              |
| 证书申请 | 签发 CA、算法、用途、有效期、自定义有效期单位         | 主表单和侧栏卡片                   | 窄屏下保持触发器等宽，不产生横向滚动；自定义有效期时三个控件在同一行按可用宽度收缩 |
| 证书撤销 | CA、撤销原因、导出格式、每页条数                      | 表格工具栏、CRL 导出弹窗、分页栏   | 使用 Portal + popper，不被表格或弹窗裁切，并按视口空间自动调整展开方向              |
| 登录     | 登录方式                                              | 仅在 LDAP 或企业微信认证启用时显示的登录表单 | 跟随登录卡片宽度并按视口自动翻转                                                    |
| 仪表盘   | 最近证书、近期审计活动条数                            | 两个卡片的标题栏                   | Portal + popper，右侧对齐触发器，均可切换 10 / 20 / 30 条；审计列表在卡片内容区滚动 |
| 审计日志 | 模块、结果                                            | 表格工具栏                         | 使用默认 popper 定位                                                                |
| 审批管理 | 每页条数                                              | 审批表格卡片底部分页栏             | Portal + popper；不受表格内部滚动裁切，并按视口空间自动向上或向下展开               |
| 通知配置 | 飞书应用接收 ID 类型                                  | 飞书应用媒介配置表单               | Portal + popper；在配置详情滚动区内不被裁切，并按视口空间自动向上或向下展开         |

当前没有保留手写 listbox 控件。新增 Select 时必须同步维护本表，并在弹窗底部、滚动容器或视口边缘实际验证展开方向与可见范围。
